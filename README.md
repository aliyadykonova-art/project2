
# Учебный проект по Python
*Проект для выполнения проверки банковских операций клиента*<br> 

**Этот проект написан на языке программирования python с использованием poetry**
## Использование и запуск проекта
Для проверки проекта по всем нормам PEP8  можете запустить из корневой папки проекта:
````cmd
poetry run flake8 .
poetry run isort .
poetry run mypy .
````
**Модуль masks.py предоставляет функции для маскирования номера карты и маски аккаунта для разных типов<br>
Модуль widget.py предоставляет функции для маскирования номера карты либо счета, и для получения даты из форматированной строки<br>
Модуль processing.py предоставляет функции для фильтрования банковских операций**
