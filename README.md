# Учебный проект по Python

Привет! Это мой учебный проект по Python. Я делаю его, чтобы научиться работать с тестами, линтерами и Poetry. Проект про банковские операции — маскировка карт, счетов, фильтрация и сортировка.

## Что умеет проект

В папке `src/` лежат три модуля.

### masks.py

Тут две функции для маскировки.

`get_mask_card_number(card_number)` — берёт номер карты из 16 цифр и возвращает что-то вроде `7000 79** **** 6361`. Если передать не строку — будет `TypeError`. Если строка не из 16 цифр или там не только цифры — будет `ValueError`.

`get_mask_account(card_number)` — берёт номер счёта и оставляет только последние 4 цифры, получается `**4305`. Ошибки те же: `TypeError` на не-строку, `ValueError` если цифр меньше 4 или есть буквы.

### widget.py

Тут функции, которые работают со строкой, где сразу написан тип и номер.

`mask_account_card(info)` — принимает строку типа `"Visa Platinum 7000792289606361"` или `"Счет 73654108430135874305"` и возвращает её же, но с замаскированным номером. Слово «счёт» ищется в конце названия, регистр не важен.

`get_date(date_str)` — превращает `"2019-07-03T18:35:29.512364"` в `"03.07.2019"`.

### processing.py

Тут фильтрация и сортировка операций.

`filter_by_state(operations, state="EXECUTED")` — оставляет только операции с нужным статусом. Если передать не список — `TypeError`.

`sort_by_date(operations, reverse=True)` — сортирует по дате. По умолчанию от новых к старым.

`get_date(op)` — достаёт дату из одной операции. Если даты нет — вернёт пустую строку.



## Как установить

Я использую Poetry, поэтому сначала его надо поставить, если ещё нет:

```bash
pip install poetry
```

Потом в папке проекта:

```bash
poetry install
```

## Как проверить код

Запускаю из корня проекта:

```bash
poetry run flake8 .
poetry run isort .
poetry run mypy .
```

## Как запустить тесты

Тесты написаны на pytest. Запускаю так:

```bash
poetry run pytest
```

Если хочу только один файл:

```bash
poetry run pytest tests/test_masks.py -v
```

Если хочу тесты по имени:

```bash
poetry run pytest -k "test_filter"
```

## Фикстуры

Общие данные я вынес в `tests/conftest.py`. Там лежат наборы транзакций с разными статусами и датами, правильные номера карт и счетов, одна ISO-дата. Ещё есть фикстуры с параметрами (`any_state`, `any_valid_card`, `any_valid_account`) — они подставляют сразу несколько значений, чтобы не писать много одинаковых тестов.

## Как я пишу тесты

Стараюсь, чтобы один тест проверял одну вещь. Если данные отличаются только значениями — использую `@pytest.mark.parametrize`. Ошибки проверяю через `pytest.raises` и указываю конкретный тип. Ещё слежу, чтобы тесты не меняли входные данные.

## Покрытие

Хочу, чтобы покрытие было не меньше 80%. Смотрю так:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Если хочу HTML-отчёт:

```bash
poetry run pytest --cov=src --cov-report=html
```

Потом открываю `htmlcov/index.html` в браузере.

Файлы `.coverage` и `htmlcov/` я добавил в `.gitignore`, чтобы они не попадали в репозиторий.

Перед тем как сделать pull request, запускаю всё сразу:

```bash
poetry run flake8 .
poetry run isort .
poetry run mypy .
poetry run pytest --cov=src
```
